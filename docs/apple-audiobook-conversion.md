# Apple 有聲書轉檔與同步指南 (WAV to M4A)

本指南說明如何將 IndexTTS 產生的 `.wav` 有聲書檔案，正確轉換為 Apple 系統（Mac 與 iPhone）支援的有聲書格式，並確保它能順利同步到手機上。

## 為什麼不能直接改副檔名？

直接將 `.wav` 的副檔名改成 `.m4a` 或 `.m4b` 是**無效且錯誤的**。
這樣做並不會改變檔案內部的編碼（依然是體積龐大的無壓縮 WAV），這會導致 Apple 的系統無法正確辨識，甚至造成同步失敗或無法播放。

因此，你必須使用工具（例如 FFmpeg）將它**真正地轉檔壓縮**成 AAC 編碼的 `.m4a` 檔案。

## 步驟一：使用 FFmpeg 進行轉檔與加入標籤

請在終端機（Terminal）中使用 `ffmpeg` 來將 `.wav` 轉為 `.m4a`。
同時，強烈建議在轉檔時順便寫入中繼資料（Metadata），這樣匯入 Apple 系統時書名與作者才不會變成亂碼。

**轉換指令範例：**
```bash
ffmpeg -i input.wav -c:a aac -vn \
  -metadata title="章節名稱" \
  -metadata artist="作者或發音人" \
  -metadata album="書本名稱" \
  -metadata genre="Audiobook" \
  output.m4a
```

- `-c:a aac`: 將音訊轉換為 AAC 格式。
- `-vn`: 移除影片軌（確保只有純音訊）。
- `-metadata ...`: 加入歌曲/有聲書標籤。
- 最後指定輸出的檔案為 `.m4a`（例如 `02-chapter-two-tagged.m4a`）。

## 步驟二：強制 Apple 系統將其識別為有聲書

即使你已經轉成 `.m4a`，如果直接拖進 Mac 的「書籍」App，有時候系統依然會不理你。
最穩定的「100% 成功」做法是透過 Mac 的「音樂」App 繞道匯入：

1. 打開 Mac 上的 **「音樂」App (Apple Music)**。
2. 將剛才用 FFmpeg 轉好的 `.m4a` 檔案拖進「音樂」App 中。
3. 在「音樂」App 中找到剛匯入的這個音軌。
4. 在它上面 **點擊右鍵** -> 選擇 **「取得資訊 (Get Info)」**。
5. 點選 **「選項 (Options)」** 分頁。
6. 將 **「媒體種類 (Media Kind)」** 的下拉選單，從「音樂 (Music)」改為 **「有聲書 (Audiobook)」**。
7. 按下確定。

> **💡 結果：**
> 「音樂」App 會把這個檔案從音樂庫中移除，並**自動將它轉移到「書籍」App 的有聲書分類中**！這時候你打開「書籍」App，就能看到它完美躺在裡面了。

## 步驟三：同步到 iPhone

請注意：**你自己匯入的有聲書，Apple 不會透過 iCloud 自動同步！**
你必須手動透過 Finder 進行一次同步。

1. 用傳輸線（或在同一個 Wi-Fi 下）將 iPhone 連接至 Mac。
2. 打開 Mac 上的 **Finder**。
3. 在左側邊欄點選你的 iPhone 裝置。
4. 在右邊畫面上方的分頁標籤中，點選 **「有聲書 (Audiobooks)」**。
5. 勾選 **「同步有聲書到 [你的 iPhone]」**。
6. 選擇「所有的有聲書」，或是選擇「所選的有聲書」並單獨勾選你要同步的書目。
7. 點擊右下角的 **「同步 (Sync)」** 或 **「套用 (Apply)」**。

同步完成後，打開 iPhone 上的「書籍」App -> 進入「有聲書」分類，即可開始聆聽。
